# Chop Wah On

Phone-first Khmer/English landing page for Chop Wah On. Next.js 15, Tailwind 4, tRPC, React Three Fiber.

## Commands

```
pnpm dev        # dev server
pnpm lint       # ESLint
pnpm typecheck  # tsc --noEmit
pnpm test       # Vitest unit tests
pnpm e2e        # Playwright (builds and starts on :3000)
```

CI (`.github/workflows/ci.yml`) runs lint, typecheck, test and e2e on every push to `main` and every pull request.
